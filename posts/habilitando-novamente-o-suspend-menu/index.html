Habilitando novamente o suspend no Omarchy-Menu

11/01/2026 [Atualizado em 11/01/2026]2 min de leitura (379 palavras)
#tutorial  #Linux  #Omarchy  #bash 

Primeiro o que aconteceu com o botão Suspend?#

![[Pasted image 20260102172909.png]] Para quem utiliza versões anteriores percebeu que no commit em 8 de dezembro na atualização para a versão v3.2.3 ![[Pasted image 20260101211929.png]] Foi retirado o menu para suspender o que gerou bastante comentários da comunidade como é possível ver nos comentários do corpo do commit ![[Pasted image 20260101212148.png]] E abaixo vemos a solução do DHH sobre adicionar uma bind para suspender o que eu achei valido, mas é ruim tirar hábitos depois de 2 versões usando o Omarchy Menu -> System -> Suspend.

bindd = SUPER CTRL, X, Suspend computer, exec, systemctl suspend

![[Pasted image 20260101212644.png]] Porem como eu gosto muito de modificar essa distro arch que tem uma grande comunidade e talvez chegue a novos usuários é uma porta de entrada para quem cansou do windows e que aprender mais de desenvolvimento de software ( mesmo não tendo mercado ). Mas como psicólogos e vendedor de curso nós temos que buscar hobbies, eu gosto de pegar distro linux e ir brincando e organizando do meu jeito.

Então como voltar com o menu Suspend?#

![[Pasted image 20260102171559.png]] Usando o commit de base podemos saber o PATH de nosso arquivo Shell-Script que nomeado a pasta bin pois ele é um script que faz apenas uma função. ![[Pasted image 20260102171833.png]] Como na instalação do omarchy o repo é clonado dentro da pasta share e lá achamos o dir bin e podemos abrir ele em nosso editor de código. ![[Pasted image 20260102172046.png]] Aonde podemos comparar com o codigo fonte no github ![[Pasted image 20260102172124.png]] vamos apenas o que foi removido em nosso arquivo local. Basicamente colocamos a String “Suspend” novamente e um case para Suspend que roda o comando systemctl suspend que usamos normalmente pela CLI. e nosso arquivo fica assim bem simples né? ![[Pasted image 20260102172513.png]]

Finalizando#

![[Pasted image 20260102172625.png]] Agora temos nossa opção de menu Suspend novamente. Bom nesse tutorial vemos um pouco primeiro sobre versionamento de uma aplicação e no seu código fonte. Como vemos a força do Linux, Distros Opensource aonde podemos fazer edições customizadas se não gostar de como o criador está dirigindo a OS. Eu acho que o DDH usa mais desktop por isso suspend pode não ser tão necessario quanto Eu usuario de notebook.
